# ✨ 每週學習花絮九宮格產生器

Joyce's ABC Adventure 系列工具之一。

輸入本週主題、target words、一句話重點，選擇 emoji 或上傳照片，
一鍵產出九宮格圖卡，用途分兩種：

| 項目 | 📸 公開分享模式 | 📩 聯絡簿附件模式 |
|---|---|---|
| 配色 | 霧薰衣草 | 棕色調 |
| 照片來源 | 強制使用 Emoji（去識別化保護孩子） | 可上傳 1-4 張實際照片 |
| 標題右上角 | Vol. 流水號 | 班級名稱 |
| 版面 | 3x3 九宮格（主題／Emoji／字彙／重點句／日期混搭） | 3x3 九宮格（主題／照片／字彙／重點句／班級／日期混搭） |

## 使用方式
1. 開啟網站
2. 選擇模式（📸 公開分享 / 📩 聯絡簿附件）
3. 填入本週主題、target words（最多 3 個）、一句話重點、班級
4. 公開模式：從 8 大分類（水果食物／動物／交通工具／天氣自然／字母學習／獎勵鼓勵／情緒表情／節慶主題）點選 3 個 Emoji
5. 聯絡簿模式：上傳 1-4 張照片，沒填滿的格子自動用班級 Emoji 佔位
6. 點擊「⬇️ 下載圖卡 PNG」

## 技術
純前端 HTML/CSS/JavaScript，Canvas API 繪圖，無需後端、無需資料庫。
所有格子文字自動換行並依內容縮放字級，避免超出邊框。
Vol. 流水號儲存在瀏覽器 localStorage（清除瀏覽器資料會重置）。

## 部署
GitHub Pages：把 `index.html` 放在 repo 根目錄，開啟 Settings → Pages 即可。
